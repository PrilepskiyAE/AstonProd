# Приложение для сортировки объектов с использованием паттернов проектирования

Консольное Java‑приложение для сортировки объектов пользовательского класса с применением паттернов «Стратегия» и «Строитель».

## Обзор проекта

Приложение реализует систему сортировки для пользовательских Java‑классов с полной поддержкой паттернов проектирования, валидации данных и многопоточности.

## Основные возможности

* **Циклическое выполнение программы** — работает до тех пор, пока пользователь не выберет выход.
* **Несколько способов заполнения данных:**
    * ручной ввод;
    * генерация случайных данных;
    * загрузка из файла.
* **Паттерн «Строитель» (Builder)** — для создания объектов.
* **Паттерн «Стратегия» (Strategy)** — для реализации разных алгоритмов сортировки.
* **Валидация данных** — для всех типов ввода (включая данные из файла).
* **Сортировка по всем 3 полям** выбранного класса.
* **Кастомная коллекция** — с заполнением через стримы.
* **Запись в файл** — режим добавления для отсортированных коллекций.
* **Многопоточный подсчёт** — параллельное вычисление количества вхождений элемента.
* **Ручное тестирование** — тесты, написанные без использования сторонних библиотек.
